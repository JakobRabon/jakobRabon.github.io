16-bit RISC CPU — Custom ISA to FPGA Implementation
02
Semester-long computer architecture project designing and implementing a fully functional single-cycle 16-bit RISC CPU in Verilog, from ISA specification through FPGA deployment. Designed a custom 16-instruction ISA supporting 4 instruction formats (R, I, B, S-type), 8 general-purpose registers, and full C construct support including arithmetic, logic, branches, loops, and function calls. Individually built and testbench-verified every datapath component — ALU, register file, branch comparator, control unit, immediate generator, PC, and multiplexers. Integrated all components into a top-level single-cycle CPU, synthesized in Vivado, and deployed on a NEXYS4 DDR FPGA with block RAM. Simulation confirmed correct execution of all 16 instructions including LW/SW with synchronous block RAM.

Digital Reaction Time Measurement System
04
Designed and implemented a two-player competitive reaction game on a NEXYS4 DDR FPGA in Verilog. Built a multi-module architecture including a clock divider (100MHz → 1ms/10kHz), cascading BCD reaction timers, a 6-state ASMD finite state machine for game flow, and a multiplexed 7-segment display driver. Players compete across selectable rounds — reaction times are captured in millisecond precision, displayed in s.ms format, and a DNF is issued if no response occurs within 5 seconds. Score tracking, winner determination, and pseudo-random start timing are all handled in hardware.

STM32 Motor Control & Feedback System
05
Bare-metal embedded C firmware for an STM32L4 microcontroller implementing a closed-loop DC motor control system. Configured TIM2 for 5 kHz PWM output with keypad-selectable duty cycles (0–100%), TIM6 for a hardware-timer-driven stopwatch with directional counting, and TIM7 for periodic ADC sampling at 16 kHz. Integrated a 4x4 matrix keypad with interrupt-driven input detection, debouncing, and a row/column scan algorithm. Implemented proportional feedback control comparing ADC-measured motor speed against a user-defined setpoint to continuously adjust PWM output — validated with oscilloscope waveforms at 20%, 50%, and 80% duty cycles.
